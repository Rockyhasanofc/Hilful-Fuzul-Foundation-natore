⚙️ সেটআপ গাইড (এই ফাইলেই সব আছে)

এখন অ্যাপ Local mode-এ চলছে। সবাই একই ডেটা দেখতে অনলাইন (Firebase) চালু করতে নিচের ধাপগুলো করে ফাইলের firebaseConfig অংশে তথ্য বসান।
  1. প্রজেক্ট: console.firebase.google.com → Add project (Analytics বন্ধ)।
  2. Login চালু: Build → Authentication → Get started → Email/Password → Enable।
  3. Database: Build → Firestore Database → Create → Location asia-south1 বা asia-southeast1 → Production mode।
  4. নিরাপত্তা নিয়ম: Firestore → Rules ট্যাবে সব মুছে নিচের লেখাটা paste করে Publish করুন (এটা না করলে ডেটা সুরক্ষিত নয়)।
  5. config: Project settings ⚙️ → Your apps → </> Web → Register → firebaseConfig-এর মানগুলো এই ফাইলের শুরুর দিকের firebaseConfig-এ (যেখানে PASTE_...) বসান।
  6. প্রথম Admin: Authentication → Users → Add user → UID কপি করুন। Firestore → Start collection users → Document ID = ওই UID → string field: role=admin, name, email।
  7. হোস্টিং: এই ফাইলটি index.html নামে Firebase Hosting বা GitHub Pages (public repo)-এ তুলুন। ডাবল-ক্লিকে খুললে login চলবে না। GitHub Pages হলে Authentication → Settings → Authorized domains-এ আপনার-নাম.github.io যোগ করুন।
  8. ব্যবহার: Admin দিয়ে ঢুকে Staff ট্যাব থেকে কর্মচারীর account বানান। পুরনো অ্যাপের Backup ফাইল Dashboard → Restore দিয়ে আনা যায়।

Firestore Rules


 

 
সীমাবদ্ধতা: Staff-এর স্ক্রিনে কেনা দাম লুকানো থাকে, কিন্তু Firebase ফিল্ড-পর্যায়ে লুকাতে পারে না। ইন্টারনেট ছাড়া Sale/Purchase সেভ হয় না। ফ্রি সীমা (দিনে ৫০,০০০ read, ২০,০০০ write) বদলাতে পারে — firebase.google.com/pricing দেখুন।
